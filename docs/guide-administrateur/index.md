# Guide administrateur

Ce guide regroupe les opérations réservées aux administrateurs ou responsables
de l'application.

Il couvre la gestion des utilisateurs, des droits, des données et des tâches de
maintenance courantes.

## Périmètre administrateur

Un administrateur peut notamment :

- créer, modifier et archiver des utilisateurs ;
- attribuer ou retirer le rôle administrateur ;
- gérer les référentiels métier utilisés dans les formulaires ;
- gérer les lignes de stock ;
- archiver des documents ;
- archiver des véhicules, assurances, contrôles techniques et interventions ;
- forcer certains enregistrements en cas d'alerte métier, par exemple sur le
  kilométrage.

## Accès aux écrans

Les entrées principales sont :

- **Utilisateurs** dans la barre latérale ;
- **Configuration** en bas de la barre latérale ;
- les actions d'administration visibles dans les fiches métier.

Le lien **Configuration** n'est affiché que pour les administrateurs.

## Principes de gestion

- Appliquer le droit minimal nécessaire.
- Vérifier l'impact métier avant de supprimer ou archiver une donnée.
- Préférer la correction d'une donnée existante à la création d'un doublon.
- Contrôler les documents ajoutés aux ressources sensibles.
- Vérifier les dépendances avant de supprimer un référentiel.

## Parcours conseillé

1. Lire [Rôles et droits](./roles-et-droits.md).
2. Configurer les [utilisateurs](./utilisateurs.md).
3. Maintenir les [paramètres](./parametres.md) métier.
4. Comprendre la [suppression logique](./donnees-et-suppression.md).
5. Appliquer les contrôles de [maintenance](./maintenance.md).
