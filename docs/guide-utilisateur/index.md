# Guide utilisateur

Ce guide explique comment utiliser l'application GMAO au quotidien.

Il s'adresse aux utilisateurs qui consultent les équipements, suivent les
interventions, ajoutent des documents ou recherchent des informations dans la
base.

## Parcours conseillé

1. Lire le [démarrage](./demarrage.md).
2. Vérifier le fonctionnement de la [connexion](./connexion.md).
3. Comprendre la [navigation](./navigation.md).
4. Consulter les pages sur les [équipements](./equipements.md) et les
   [interventions](./interventions.md).
