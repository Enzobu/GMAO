# Contrôles Techniques

Les contrôles techniques sont rattachés à un véhicule et permettent de suivre
les dates de contrôle, les échéances de validité, le kilométrage et les
contre-visites.

## Accéder aux contrôles

Depuis une fiche véhicule, cliquez sur **Voir les contrôles**.

La liste affiche :

- la date du contrôle ;
- le résultat ;
- la présence ou non d'une contre-visite ;
- la date de validité ;
- le kilométrage ;
- la date limite de contre-visite ;
- le centre de contrôle.

## Résultats disponibles

Les résultats possibles sont :

- **Favorable** ;
- **Contre-visite** ;
- **Défavorable**.

Une contre-visite est requise dès que le résultat n'est pas **Favorable**.

## Ajouter un contrôle technique

Depuis la liste des contrôles du véhicule, cliquez sur **Ajouter**.

Champs disponibles :

- date du contrôle, obligatoire ;
- date de validité ;
- kilométrage, obligatoire ;
- résultat, obligatoire ;
- date limite de contre-visite si nécessaire ;
- centre, obligatoire ;
- notes ;
- documents, uniquement à la création.

## Dates calculées automatiquement

Quand vous renseignez la date du contrôle :

- la date de validité est proposée à 2 ans moins 1 jour ;
- la date limite de contre-visite est proposée à 14 jours si le résultat exige
  une contre-visite.

Ces dates peuvent être modifiées si nécessaire.

## Alerte kilométrage

Si le kilométrage saisi entre en conflit avec le kilométrage connu du véhicule,
une alerte peut apparaître.

Un administrateur peut forcer l'enregistrement si le conflit est volontaire.

## Modifier ou supprimer un contrôle

Le propriétaire du véhicule ou un administrateur peut modifier un contrôle.

La suppression est réservée aux administrateurs et masque le contrôle de la
plateforme.
