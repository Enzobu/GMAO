# Captures d'écran

Cette page liste les captures à ajouter pour illustrer le guide utilisateur.

Placez les images dans :

```text
docs/public/images/captures/
```

## Format recommandé

- Format : `.png`.
- Largeur : écran desktop complet si possible.
- Données : utiliser des données de démonstration, jamais de données sensibles.
- Nom : minuscules, mots séparés par des tirets.
