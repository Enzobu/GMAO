# Messages et alertes

L'application utilise plusieurs types de messages pour informer l'utilisateur.

## Messages de succès

Ils confirment qu'une action s'est bien déroulée, par exemple :

- profil mis à jour ;
- email de réinitialisation envoyé ;
- document ajouté ;
- données enregistrées.

## Messages d'erreur

Ils apparaissent lorsqu'une action ne peut pas être réalisée.

Exemples fréquents :

- identifiants invalides ;
- formulaire incomplet ;
- fichier trop volumineux ;
- document impossible à ouvrir ;
- liste impossible à charger.

## Alertes métier

Certaines alertes demandent une décision utilisateur :

- clôturer une assurance active existante ;
- confirmer la restauration des pièces en stock ;
- confirmer un archivage ;
- gérer un conflit de kilométrage.

## Bouton cloche

Le bouton cloche est présent dans l'en-tête, mais aucune notification métier
active n'est actuellement documentée.

## Que faire en cas d'erreur ?

Notez :

- la page concernée ;
- l'action réalisée ;
- le message affiché ;
- l'heure approximative ;
- le véhicule ou la ressource concernée.

Ces informations facilitent le diagnostic par un administrateur.
