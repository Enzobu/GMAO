# Problèmes fréquents

## Je suis redirigé vers la connexion

Votre session a probablement expiré. Reconnectez-vous.

## Je ne vois pas une donnée attendue

Vérifiez les filtres actifs et vos droits d'accès.

## Un document ne s'ouvre pas

Reconnectez-vous puis réessayez. Si le problème persiste, contactez un
administrateur.
