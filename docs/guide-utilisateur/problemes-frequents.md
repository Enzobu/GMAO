# Problèmes fréquents

## Je suis redirigé vers la connexion

Votre session a probablement expiré.

Reconnectez-vous. Si cela se reproduit immédiatement, contactez un
administrateur.

## Identifiants invalides

Vérifiez l'email et le mot de passe.

Si vous avez oublié votre mot de passe, utilisez **Mot de passe oublié ?** sur
la page de connexion.

## Je ne vois pas une donnée attendue

Vérifiez :

- les filtres actifs ;
- la pagination ;
- vos droits d'accès ;
- le module consulté, par exemple liste globale ou liste d'un véhicule.

## Un bouton d'ajout ou de modification n'apparaît pas

Vous n'avez probablement pas les droits nécessaires.

Les actions de modification sont généralement réservées au propriétaire de la
ressource ou aux administrateurs.

## Un véhicule est en lecture seule

Vous pouvez le consulter, mais vous n'êtes ni propriétaire du véhicule ni
administrateur.

## Impossible d'ajouter une pièce à une intervention

Vérifiez que la pièce existe dans le stock et qu'elle est compatible avec le
véhicule concerné.

Une pièce sans véhicule compatible ne peut pas être utilisée dans une
intervention.

## Le kilométrage déclenche une alerte

Le kilométrage saisi peut être incohérent avec le dernier kilométrage connu du
véhicule.

Vérifiez la valeur. Si elle est correcte, demandez à un administrateur de
forcer l'enregistrement si nécessaire.

## Un document ne s'ouvre pas

Reconnectez-vous puis réessayez.

Si le problème persiste, vérifiez que vous avez accès à la ressource concernée
et contactez un administrateur.

## Fichier trop volumineux

La taille maximale est de 8 Mo.

Compressez le fichier, notamment les PDF, puis réessayez.

## La liste est vide

Réinitialisez les filtres et vérifiez la pagination.

Si la liste reste vide, il n'existe peut-être aucune donnée dans votre périmètre
ou votre rôle ne permet pas d'y accéder.

## Une suppression ne supprime pas réellement la donnée

Les suppressions visibles dans l'application correspondent à un archivage ou une
suppression logique.

La donnée est masquée de la plateforme mais n'est pas forcément supprimée
physiquement de la base.
