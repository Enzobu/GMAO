# Connexion

La connexion se fait depuis la page `/login` avec vos identifiants.

Après une connexion réussie, l'application conserve la session localement et
ajoute automatiquement le jeton d'authentification aux requêtes vers l'API.

Si votre session expire, vous êtes redirigé vers la page de connexion.

## En cas d'échec

- vérifiez l'adresse e-mail ou l'identifiant utilisé ;
- vérifiez le mot de passe ;
- contactez un administrateur si le compte est désactivé ou inconnu.
