# Tableau de bord

Le dashboard est le point d'entrée principal après la connexion.

Il donne une vue globale du parc automobile et aide à repérer les échéances à
surveiller.

## Indicateurs

La première ligne affiche quatre indicateurs :

- **Véhicules** : nombre de véhicules suivis ;
- **Entretiens** : nombre d'interventions/entretiens ;
- **Entretiens à jour** : pourcentage de véhicules à jour, avec le détail du
  nombre de véhicules concernés ;
- **Alertes** : nombre d'éléments nécessitant une attention.

## Activité à venir

La section **Activité à venir** liste les événements à surveiller dans les 30
prochains jours :

- entretiens prévus ;
- assurances ;
- contrôles techniques.

Les éléments peuvent être mis en avant avec un niveau d'alerte, par exemple
warning ou danger.

## Historique des entretiens

Le graphique annuel affiche le nombre d'entretiens par période.

Utilisez les flèches pour changer d'année et comparer l'activité d'une année à
l'autre.

## Activité récente

La section **Activité récente** liste les assurances, contrôles et interventions
ajoutés sur les 30 derniers jours.

Elle sert à vérifier rapidement les dernières actions enregistrées.

## Si le dashboard ne charge pas

Un message d'erreur apparaît si les données ne peuvent pas être récupérées.

Dans ce cas, actualisez la page. Si le problème persiste, reconnectez-vous puis
contactez un administrateur.
