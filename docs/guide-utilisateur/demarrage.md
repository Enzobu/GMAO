# Démarrage

L'application GMAO centralise le suivi du parc automobile : véhicules,
assurances, contrôles techniques, interventions, pièces de stock et documents.

## Prérequis

Avant de commencer, vérifiez que vous disposez :

- d'un compte utilisateur actif ;
- d'un navigateur récent ;
- d'un accès réseau à l'application ;
- des droits nécessaires pour consulter ou modifier les véhicules concernés.

## Premier accès

1. Ouvrez l'application dans votre navigateur.
2. Connectez-vous avec votre email et votre mot de passe.
3. Vérifiez votre nom dans le menu utilisateur en haut à droite.
4. Consultez le dashboard pour obtenir une vue globale du parc.

## Organisation générale

La barre latérale donne accès aux modules principaux :

- **Accueil** : dashboard global ;
- **Véhicules** : parc automobile et fiches véhicules ;
- **Interventions** : liste globale en lecture ou suivi par véhicule ;
- **Stock** : pièces disponibles et compatibilités véhicules ;
- **Utilisateurs** : liste des utilisateurs selon les droits ;
- **Documentation** : ouvre cette documentation ;
- **Paramètres** : personnalisation de l'apparence ;
- **Configuration** : visible uniquement pour les administrateurs.

## Bonnes pratiques

- Recherchez d'abord une donnée avant de la recréer.
- Vérifiez les filtres actifs si une liste semble vide.
- Ajoutez les documents utiles dès la création d'une assurance, d'un contrôle,
  d'une intervention ou d'une ligne de stock.
- Utilisez les notes pour conserver les informations métier non structurées.
