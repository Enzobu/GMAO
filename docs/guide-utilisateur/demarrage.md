# Démarrage

L'application GMAO centralise le suivi des équipements, des interventions et
des documents associés.

Avant de commencer, vérifiez que vous disposez :

- d'un compte utilisateur actif ;
- d'un navigateur récent ;
- des droits nécessaires pour accéder aux données de votre périmètre.

Une fois connecté, le tableau de bord donne accès aux informations principales
et la barre latérale permet de naviguer entre les modules.
