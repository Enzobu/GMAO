# Navigation

L'application est structurée autour d'une barre latérale, d'un en-tête fixe et
d'un fil d'Ariane.

## Barre latérale

La barre latérale permet d'accéder aux sections principales :

- **Accueil** : dashboard ;
- **Véhicules** : liste et fiches véhicules ;
- **Interventions** : liste globale des interventions ;
- **Stock** : pièces et compatibilités ;
- **Utilisateurs** : utilisateurs visibles selon les droits ;
- **Documentation** : ouverture de la documentation dans un nouvel onglet ;
- **Paramètres** : palettes de couleurs ;
- **Configuration** : section réservée aux administrateurs.

Sur mobile, ouvrez le menu avec le bouton situé en haut à gauche.

## En-tête

L'en-tête contient :

- la recherche globale ;
- le bouton de changement de thème clair/sombre/système ;
- l'accès au menu utilisateur ;
- la déconnexion.

Le bouton cloche est présent dans l'interface, mais aucune notification métier
n'est actuellement documentée comme active.

## Fil d'Ariane

Le fil d'Ariane apparaît au-dessus du contenu. Il indique votre position dans
l'application et permet de revenir rapidement aux niveaux précédents.

Exemple :

```text
Accueil > Véhicules > Véhicule > Interventions > Intervention
```

## Menu utilisateur

Le menu en haut à droite affiche vos initiales, votre nom ou votre email, ainsi
que votre rôle.

Il permet d'accéder aux **Paramètres du profil** et à la **Déconnexion**.
