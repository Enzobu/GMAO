# Recherche et filtres

L'application propose deux niveaux de recherche : la recherche globale dans
l'en-tête et les filtres propres à chaque liste.

## Recherche globale

Le champ **Rechercher...** est disponible dans l'en-tête.

Vous pouvez l'ouvrir avec le raccourci clavier :

```text
Ctrl + K
```

Sur macOS, le raccourci `Cmd + K` fonctionne également.

La recherche commence à partir de 2 caractères et affiche jusqu'à 12 résultats.

## Catégories recherchées

La recherche globale interroge :

- véhicules ;
- interventions ;
- stock ;
- utilisateurs, uniquement pour les administrateurs.

Appuyez sur `Entrée` pour ouvrir le premier résultat ou cliquez sur le résultat
souhaité.

Appuyez sur `Échap` pour fermer les résultats.

## Filtres de liste

Les listes disposent de filtres dédiés :

- véhicules : recherche, type, statut, droit, tri ;
- interventions : recherche, statut ;
- stock : recherche, véhicule, type, statut de stock, tri ;
- utilisateurs : recherche, rôle, droit, tri.

## Pagination

Les listes paginées affichent le nombre total d'éléments et permettent de
changer :

- de page ;
- le nombre d'éléments par page.

Le choix du nombre d'éléments par page est conservé localement dans le
navigateur.

## Réinitialiser les filtres

Si vous ne retrouvez pas une donnée, utilisez d'abord le bouton de
réinitialisation des filtres.

Une liste vide peut simplement venir d'un filtre actif trop restrictif.
